# GymOS — Commercial Multi-Tenant Gym Management ERP SaaS

GymOS is a commercial-grade, white-label Multi-Tenant Gym Management ERP SaaS engineered specifically for the Indian fitness market.

## Technology Stack
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend & Database:** Supabase (PostgreSQL 17, Row Level Security, Auth, Storage, Edge Functions)
- **Deployment:** Vercel
- **Payments:** Razorpay (UPI, Net Banking, Cards)
- **Communications:** WhatsApp Business Cloud API, Email, SMS
